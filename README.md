# جهت حمله

نقشهٔ حرارتی و مسیر اسپک والیبال، از روی فایل اسکاوت DataVolley (`.dvw`). فایل را با [pydatavolley](https://github.com/openvolley/pydatavolley) می‌خواند؛ همان قالب فایل را پکیج R به نام [datavolley](https://datavolley.openvolley.org/) تعریف کرده است. رابط شاینی نیست.

با انتخاب بازیکن، هر ترکیب حمله زمین خودش را می‌گیرد: سه زمین در هر ردیف، و کدهای بعدی در ردیف پایین. زیر هر زمین تعداد حمله، کارایی و موفقیت نوشته شده. کارایی یعنی (امتیاز − خطا − بلاک) تقسیم بر تعداد حمله، و موفقیت یعنی سهم امتیاز از همان حمله‌ها. نقشهٔ حرارتی فقط از مختصات واقعی فرود ساخته می‌شود و اوج قرمز روی همان نقطه است. خط جهت، مستقیم از محل ضربه تا نقطهٔ فرود می‌رود. توپی که بیرون خط فرود آمده بیرون خط می‌ماند.

تب «سرویس» همان سه حالت را برای سرویس دارد: نقشهٔ حرارتی روی محل فرود، خط جهت از نقطهٔ زدن سرویس (پشت خط انتهایی) تا فرود، و هر دو با هم. نوع سرویس (حرف Q یا M و بقیه) مثل کد حمله، سه زمین در هر ردیف می‌گیرد. زیر هر زمین تعداد سرویس، کارایی و موفقیت است. کارایی سرویس یعنی (ایس − خطا) تقسیم بر تعداد سرویس، و موفقیت یعنی سهم ایس. سرویس‌هایی که مختصات فرود ندارند وسط منطقهٔ آن‌طرف تور گذاشته می‌شوند و داخل نقشهٔ حرارتی نیستند.

فاز حمله، نوع ضربه، چرخش یا یک زمین واحد، و رنگ زمین را می‌شود عوض کرد. خروجی PNG، JPEG و PDF است. عوض کردن رنگ زمین مختصات را جابه‌جا نمی‌کند. مدل پیش‌فرض «برگ مربی» است؛ سالن آبی، سبز، قرمز، پارکت، ساحلی و تختهٔ تیره هم هستند.

## اجرا

```bash
python3 -m pip install -r parser/requirements.txt
npm install
npm run dev
```

اپ روی [http://127.0.0.1:4317](http://127.0.0.1:4317) بالا می‌آید.

`pandas` باید نسخهٔ ۲ باشد. pydatavolley با pandas ۳ سازگار نیست.

بازی نمونه، فایل اوکراین – رومانی (قهرمانی اروپا، ۲۰ سپتامبر ۲۰۲۶) است که همراه پروژه گذاشته شده: `parser/fixtures/ukr-rom-2026.dvw`.
